# Pasta `assets/` (opcional)

O jogo **não precisa de nenhum arquivo aqui**: todos os gráficos são desenhados com funções da
raylib e todos os sons/música são gerados por código (`src/audio.c`). Esta pasta existe para
você personalizar o jogo, se quiser.

| Arquivo (opcional)              | Efeito                                                              |
|---------------------------------|---------------------------------------------------------------------|
| `fonts/game_font.ttf`           | Substitui a fonte padrão. Suporta acentos do português (Latin-1).   |
| `sounds/music.ogg` (ou `.mp3`/`.wav`) | Substitui a música gerada por código.                         |

## Importante: licenças e créditos

Qualquer arquivo que você adicionar **precisa ter licença compatível** com o seu uso (por exemplo
CC0, CC-BY, OFL, MIT) e **deve ser registrado na seção "Créditos" do `README.md`** com título,
autor, fonte (link) e licença. Não use músicas, sprites ou fontes comerciais/protegidos sem autorização.
